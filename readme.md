# Java Learning Practice

This repository contains Java programs created during learning core Java and data structure concepts.

## Overview

The exercises cover:
- Java basics and syntax
- Object-oriented programming
- Arrays and loops
- Binary Search Trees (BST)
- Tree traversal and ancestor problems
- Iterators and stack-based traversal
- Finding the largest valid BST in a binary tree

## Files in this project

- `first.java` - Basic Java practice with 2D arrays and nested loops.
- `second.java` - Simple class, constructor, and object property example.
- `PredSucc.java` - Finds predecessor and successor of a given key in a BST.
- `BSTIterator.java` - Implements a custom BST iterator using a stack.
- `largestBST.java` - Calculates the size of the largest valid BST in a tree.
- `MergeBST.java` - BST building and inorder traversal practice.

## How to run a Java file

Open a terminal in this folder and run:

```bash
javac <FileName>.java
java <ClassName>
```

Example:

```bash
javac PredSucc.java
java predSucc
```

> Note: The Java class name must match the filename for compilation and execution.
